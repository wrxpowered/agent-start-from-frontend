# 学习方式说明

本文件用于指导整个学习项目的讲解方式，不是额外的课程或前置阶段。

## 讲解原则

用户有 Web 前端开发经验。优先从 TypeScript 和熟悉的工程问题切入，再解释 AI / Agent 新概念；不假设数学、后端、数据库、网络、命令行或部署基础已经熟练。

默认采用以下节奏：

1. 给出一段足够小的代码或具体工程场景。
2. 解释代码背后的关键概念，以及它解决的问题。
3. 说明在 Agent 系统中有哪些不同点、边界或常见错误。
4. 必要时用一个简短问题或修改任务确认理解。

这不是要求每节课都先写代码，也不是纯代码驱动。代码是概念讲解的切入点；当代码本身不利于理解时，先用简短例子说明即可。

## 控制认知负担

- 一次聚焦少量新概念，避免堆叠术语和重复解释。
- 使用最小而有意义的示例，减少冗长背景、重复表格和装饰性排版。
- 明确区分当前必须掌握、理解大意即可、以后按需学习。
- 不为凑时长增加内容；学习单元按完整性和实际理解推进。
- 如果用户没有理解，换一种讲法或换一个例子，不用增加更多术语来掩盖断点。

## 数学与工程基础

- 不要求先学完高等数学、线性代数或概率论再开始 AI。
- 只有当前任务确实需要时才引入公式，并解释符号和用途。
- HTTP、服务端、数据库、环境变量、依赖管理、部署和日志等概念第一次出现时应说明其作用。
- 后端、安全和数据库知识以当前 Agent 项目需要为准，不扩展成完整后端工程课程。

## 本项目的目标

目标不是降低工程标准，而是让学习过程更直接、易理解且可验证。最终仍要能独立解释设计、编写和调试代码、测试边界条件，并说明系统限制。
