# Agent Start From Scratch

从 Web 前端工程师出发，系统学习 AI / LLM 与 Agent 工程，并通过持续迭代的项目积累可验证的工程能力。

## 学习目标
建立从模型基础到可上线 Agent 系统的工程能力，逐步掌握 Python、RAG、工具调用、Agent 编排、MCP 与生产级实践。

## 学习路线
1. AI / LLM 基础
2. Python 工程基础
3. RAG（检索增强生成）
4. Tool Calling（工具调用）
5. Agent（智能体编排与执行）
6. MCP（模型上下文协议）
7. 生产级 Agent 工程

## 当前进度
- 当前阶段：AI / LLM 基础（进行中，尚未完成）
- 已练习：Token 基础、售后客服结构化 JSON、意图与缺失字段识别、Agent 交互流程意识、后端校验边界。
- 当前重点：完善结构化输出 Schema、缺失信息追问和状态流转。

## 学习方式
每个学习单元约 1–2 小时，包含路线定位、概念讲解、动手练习和可检查的学习结果。进度按实际完成的学习单元记录，不按日历天数推进。优先使用云端模型/API，不要求本地运行大型模型。
