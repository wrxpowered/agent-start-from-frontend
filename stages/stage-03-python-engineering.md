# 阶段三：Python 工程基础

> 目标：达到能够阅读、编写、测试和维护常见 Python AI 服务代码的水平，而不是追求短期内精通整门语言。

## 学习范围

1. Python 语法、函数、模块和异常
2. 列表、字典、集合及常见数据处理
3. 类型标注和数据模型
4. 虚拟环境、依赖管理和项目配置
5. HTTP 请求与 API 服务
6. Pydantic 等数据校验方式
7. 同步与异步编程的基本区别
8. 日志、测试和错误处理
9. 项目结构、代码复用和配置管理
10. Python 服务与现有 TypeScript 应用之间的接口协作

## 实践项目：轻量 Python AI 服务

开发一个可被 HTTP 调用的服务：
- 接收并校验结构化请求。
- 执行文本处理或调用模型 API。
- 返回符合约定的数据结构。
- 处理无效输入、外部服务失败和超时。
- 提供基本自动化测试和运行说明。

## 阶段验收标准

- 能读懂常见 Python 项目的主要结构。
- 能独立实现简单 API 服务和数据校验。
- 能管理虚拟环境与依赖。
- 能为关键逻辑编写测试和错误处理。
- 能解释同步与异步在 I/O 场景中的基本区别。

## 学习边界

先掌握 AI 应用开发实际需要的 Python。复杂算法和数学推导按项目需要补充，不作为本阶段普遍前置条件。
