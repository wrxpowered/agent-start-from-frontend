# 阶段五：Tool Calling 与 Agent

> 目标：从一次性生成回答，进阶到能够调用工具、检查结果、维护状态并完成多步骤任务的系统。

## 学习范围

1. Tool Calling 的调用流程
2. 工具定义、参数 Schema 和返回值
3. 参数校验、权限边界和业务规则
4. 手动实现简化的 Agent 循环
5. ReAct 等常见执行模式
6. 任务分解、规划、执行和结果检查
7. 会话状态、短期记忆与长期记忆的适用场景
8. 工具失败、重试、停止条件和循环限制
9. 人工确认（Human-in-the-loop）
10. 日志、任务追踪和失败恢复
11. Agent 框架的收益、代价和适用条件

## 实践项目：多步骤任务 Agent

例如构建售后任务 Agent，使其能够查询订单、核对售后条件、提出处理建议，并在高风险或有副作用的操作前请求人工确认。

系统必须区分模型建议、工具返回的事实和后端最终执行结果。不能仅凭模型生成内容直接执行退款、付款或权限敏感操作。

## 阶段验收标准

- 能独立定义工具接口并校验参数。
- 能解释并实现一个基本的 Agent 执行循环。
- 能管理任务状态、停止条件和失败路径。
- 能防止无效参数、无限循环和不必要的重复执行。
- 能判断哪些操作可以自动执行、哪些需要人工确认。
- 能用运行记录解释一次任务为什么成功或失败。

## 学习顺序

先手动实现核心机制，再按实际需求引入框架。不要将“会用框架”误认为理解 Agent 的工作原理。
