# Python 按需补充模块

> 定位：这是贯穿核心路线的辅助能力模块，不是进入 Agent 学习前必须完成的独立阶段。

## 为什么要学 Python

Python 在 AI 工程、数据处理、RAG 生态和不少 Agent 框架中很常见。掌握它能扩大工具和框架选择范围，但学习 Python 本身不是转型的最终目标。LLM 基础、模型 API、Tool Calling 和 Agent 的核心机制可以先用熟悉的 TypeScript 学习。

## 投入比例

初始建议将 Python **专项学习**预算控制在整个规划总投入的约 10%–15%。这是帮助控制学习范围的估算，不是必须完成的课时指标；实际比例应根据项目技术选型调整。使用 Python 实现 RAG 或框架功能的时间，可以同时服务于对应的 AI 工程目标，不必全部算作语言专项学习。

## 学习内容：先学这些

1. 基础语法、变量、条件、循环和函数
2. 列表、字典、集合与常见数据处理
3. 模块、包、导入和项目结构
4. 异常处理、类型标注和数据模型
5. 虚拟环境、依赖管理、配置和环境变量
6. HTTP 请求与 JSON 数据处理
7. 同步与异步编程的基本区别，尤其是 I/O 场景中的 async / await
8. 日志、单元测试和调试
9. 按实际项目需要补充 Pydantic、FastAPI 或相关 AI 库

## 何时集中补充

- RAG 项目选择了 Python 生态中的文档处理、Embedding 或检索工具。
- 需要使用的 Agent 框架或评估工具主要支持 Python。
- 需要阅读、修改或维护团队现有的 Python AI 服务。
- 在实际编码中发现语言本身成为主要障碍，而非 AI 概念尚未理解。

遇到上述情况时，围绕当前项目集中补齐所需部分；完成项目后再决定是否继续深入。

## 暂时不需要系统学习

- 完整的数据科学课程
- NumPy / Pandas 的所有功能
- 复杂算法题训练
- 深度学习数学与模型训练
- 微调、训练基础模型或 GPU 本地部署

这些内容只有在后续目标明确要求时再安排。

## 模块验收标准

- 能读懂常见 Python 项目的入口、依赖和主要模块。
- 能编写处理 JSON、列表和字典的简单函数。
- 能使用虚拟环境安装依赖并运行项目。
- 能为关键逻辑添加类型约束、异常处理和基本测试。
- 能在需要时修改简单 API 或数据处理代码。
- 能说明自己何时需要继续查文档，而不要求背熟整门语言。

## 学习原则

不要为了“先把 Python 学完”而推迟 LLM、RAG 或 Agent 项目。学到能解决当前问题即可；当更复杂的项目确实需要时，再继续补齐。
