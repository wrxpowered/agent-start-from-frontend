# 阶段七：生产级 Agent 工程

> 目标：把实验性 AI 项目改造成可评估、可观测、可控制风险、可部署和可维护的工程产品。

## 学习范围

1. 评估集、回归测试和任务成功率
2. 工具调用正确性、回答质量与检索质量评估
3. 日志、Trace、运行过程回放和故障定位
4. Token、成本、延迟与性能优化
5. Prompt Injection 和不可信内容处理
6. 身份认证、工具权限、速率限制和密钥管理
7. 敏感信息保护与数据最小化
8. 队列、异步任务、超时和取消
9. 幂等性、重复执行防护、中断与恢复
10. CI/CD、部署、环境配置与版本管理
11. 监控、告警和故障排查
12. 项目文档、架构说明和作品集整理

## 实践项目：生产化改造

选择已有的 RAG 或 Agent 项目，针对可靠性、安全性和可维护性进行一轮改造。

项目至少应具备：
- 可重复运行的评估和回归测试。
- 可追踪的关键执行过程。
- 明确的工具权限与人工确认边界。
- 对失败、超时和重复执行的处理。
- 对成本与延迟的基本观察。
- 可复现的部署流程和清晰的项目文档。

## 阶段验收标准

- 能通过测试或评估结果说明系统质量，而非只凭 Demo 展示。
- 能追踪关键步骤并定位常见失败。
- 能解释主要安全风险及对应控制措施。
- 能处理超时、重复执行和任务恢复等关键场景。
- 能部署系统，并让其他人按照文档复现运行。
- 能说明架构选择、已知限制和后续改进方向。

## 最终作品集

优先形成三个有连续关系的项目：
1. AI 对话应用：展示模型接入与基本应用工程。
2. RAG 知识库：展示检索、引用和质量评估。
3. Agent 工程产品：展示工具调用、状态管理、权限、安全、可观测性和部署。

不要求三个项目完全独立；允许在前一项目上逐步演进，以工程深度和可解释性为优先。
