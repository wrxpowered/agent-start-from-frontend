# AI / LLM 基础学习笔记

## Token 初步认识
- 模型处理文本时会将内容切分成 Token；Token 不等同于汉字、单词或字符。
- 在其他条件相近时，减少输入内容通常会减少 Token 消耗，但具体数量取决于语言、文本内容和分词规则。
- 控制上下文长度既能帮助管理成本，也能减少无关信息干扰；不能为了省 Token 而删掉完成任务所必需的约束。

## 售后客服结构化提取练习
用户表达：“耳机右边没声音了”，希望优先换货，换不了则退款。

```json
{
  "product": "耳机",
  "problem": "右边没声音了",
  "primary_intent": "换货",
  "fallback_intent": "退款",
  "fallback_condition": "换不了",
  "purchase_time_text": "上周",
  "order_id": null,
  "paid_amount": null
}
```

## 当前理解
- 结构化输出可以把自然语言转为程序可处理的字段。
- `order_id`、`paid_amount` 等缺失字段不能凭空猜测；需要根据业务流程向用户追问，或从可信后端数据源获取。
- “换货优先，无法换货再退款”是流程与业务规则，不应只依赖模型自由发挥。
- 模型可以识别意图并生成下一步建议；后端应校验订单、资格、库存、金额和权限，并决定是否真正执行。
- Agent 不只是单次回答，还涉及状态、工具调用、结果检查、失败处理和必要的再次交互。
